# dav1dushka.github.io

Personal site of Davyd Velychko — https://dav1dushka.github.io

- One HTML file: plain HTML, CSS and a little JavaScript, no frameworks, no build step.
- 0 trackers, 0 cookies, 0 external requests.
- Works with JavaScript disabled; the animated background and the terminal are progressive enhancements.
- Respects `prefers-reduced-motion`.

Keys on the page: `1`–`6` jump to sections, `/` opens the terminal (try `help`).
